# AllSafe AI Trading — Known Limitations & Residual Risks (`KNOWN_LIMITATIONS_AND_RESIDUAL_RISKS.md`)

- **Audit Date**: November 5, 2026
- **Verification Branch**: `audit/landing-auth-integration-verification`

## 1. Verified Architectural Limitations & Operational Mitigations

| Area | Known Limitation / Residual Risk | Current Mitigation & Operational Recommendation |
| :--- | :--- | :--- |
| **1. Multi-Worker Rate Limiting & Session State (`AuthStore`)** | `AuthStore` (`apps/api/app/auth/store.py`) stores sliding-window IP rate-limit buckets (`_ip_login_buckets`), failed-login counters (`_failed_attempts`), and active sessions (`_sessions`) in thread-safe process memory (`threading.RLock()`). If the FastAPI backend is scaled horizontally across `N > 1` Uvicorn worker processes or container instances without a shared Redis/PostgreSQL store, the effective per-IP rate limit scales to `N * login_rate_limit_per_minute` and session revocation is local to each worker unless sticky sessions or a shared backing store are used. | Run a single Uvicorn process with async/thread concurrency on Render Standard/Starter (current deployment topology) and configure `AUTH_SECRET_KEY` explicitly in environment variables. For multi-instance horizontal scaling, wire `_ip_login_buckets` and `_sessions` to Supabase PostgreSQL (`public.app_users` / `public.admin_audit_logs`) or Redis. |
| **2. Proxy Trust Topology (`TRUST_PROXY_HEADERS` & `TRUSTED_PROXY_HOPS`)** | `extract_client_ip()` defaults to `trust_proxy_headers=True` and `trusted_proxy_hops=1`, which matches Render / Vercel / Nginx single-reverse-proxy deployments where the ingress load balancer appends the true client IP to `X-Forwarded-For`. If an additional CDN layer (such as Cloudflare proxy + Render ingress = 2 hops) is placed in front of the API without updating `TRUSTED_PROXY_HOPS=2`, the rightmost hop could be the CDN edge IP unless `CF-Connecting-IP` or `TRUSTED_PROXY_HOPS=2` is configured. | When deploying behind a single reverse proxy (Render), keep `TRUSTED_PROXY_HOPS=1`. If placing Cloudflare in front of Render, add Cloudflare's edge CIDRs to `TRUSTED_PROXY_CIDRS` or set `TRUSTED_PROXY_HOPS=2`. If exposing Uvicorn directly to the public internet without a reverse proxy, set `TRUST_PROXY_HEADERS=false`. |
| **3. Offline Sandbox Environment Constraints** | Outbound internet connectivity is disabled inside this verification sandbox VM, preventing direct `git push` to `github.com`, live remote Vercel preview deployment triggering, and live Groww API socket connections during this audit session. | All commits, patches (`.patch`), portable Git bundles (`.bundle`), CI workflow definitions (`.github/workflows/ci.yml`), and the one-command `publish_to_github.sh` script have been verified locally and packaged for immediate push from Termux or any internet-connected workstation. |
| **4. Static Offline NSE/BSE Holiday Calendar Horizon (`2025–2027`)** | `apps/web/src/lib/indianMarketStatus.ts` bundles official NSE/BSE trading holidays and Diwali Muhurat sessions for `2025–2027` (`MIN_VERIFIED_CALENDAR_YEAR = 2025`, `MAX_VERIFIED_CALENDAR_YEAR = 2027`). Beyond `2027`, the badge safely returns `"MARKET STATUS UNAVAILABLE"` rather than guessing. | Update `NSE_TRADING_HOLIDAYS` annually when the NSE December circular is published, or connect an optional server-side calendar endpoint. |
